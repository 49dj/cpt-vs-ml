# Public code only

The repository contains no study dataset. No original, cleaned, processed,
augmented, anonymised, renamed, or derived CPT data are redistributable through
this release. Data access and use require the relevant owners' permission; this
repository cannot grant that permission. Contact the corresponding authors of the
associated paper for guidance rather than assuming public download availability.

The example generator was written independently for this software demonstration.
It does not read research files or reproduce their distribution, sample count or
study results. Private user inputs belong in an untracked directory; derived
outputs and trained models must also remain private when based on restricted data.
`.gitignore` reduces accidental staging; it is not a substitute for reviewing Git.
